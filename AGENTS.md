# AGENTS.md: repo router

This repo supports one workstream: GC job applications. When the user
mentions postings, screening questions, GCjobs, resumes, or interviews,
READ `applying/AGENTS.md` and follow it exactly. The context files it
lists are the source of truth; read them in the order it specifies before
doing any application work.

## Shared rules

- Evidence over assertion: cite the context files for claims; flag thin
  evidence rather than papering over it
- Ask instead of guess: facts only the applicant knows (dates, magnitudes,
  attributions, willingness) get asked, never invented
- Never upgrade verb ceilings or honesty tiers recorded in EVIDENCE-MAP
  or PERSONAL-PROJECTS
- Never use em dashes in any writing. Ever. Use commas, colons,
  semicolons, periods, or parentheses instead
