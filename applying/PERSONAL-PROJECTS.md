## Honesty tiers (internal only, never paste)

- HAND: code passed through your hands; you wrote or directly edited it
- DIRECTED: AI-drafted under your direction; you verified each change
  and can explain every decision

Verb ceilings below respect this. Never upgrade. If a project is
DIRECTED, verbs like designed/verified/tested are honest; "wrote every
line" is not.

## Entry format

One section per project:

- Name and one-line what-it-is
- Scope facts: platforms, rough size, duration, commits/releases,
  test counts (numbers you can defend)
- Real fixes and hard-won lessons (interview probes land here)
- Verbs: the ceiling set
- Use for: which question types this project leads
