# ANSWER BANK: reusable STAR answers

One section per qualification type. Each entry: the typical question
phrasing, the working answer, character count, verification checklist,
and where it has been used. Draft in POSTINGS/ files first; promote
proven answers here.

How to use:
1. New posting → copy the matching entry into the posting file, adapt to
   the qualification's exact wording and char limit.
2. After results come in, note screened in/out on the entry and refine.
3. Weak entries get rewritten with new evidence, not deleted: history
   helps.

Phrasings marked **[OBSERVED]** come from real GC screening questions
(see `old-screening-questions.md`). Opening convention for yes/no
questions is in STAR-GUIDE §3 rule 9.

## Usage log

One line per application: which bank entries anchored which questions,
and the outcome when known. This is how you learn which entries actually
work.
