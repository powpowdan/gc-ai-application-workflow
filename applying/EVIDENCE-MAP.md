# EVIDENCE MAP: skill claims to backing

Crosswalk between resume keywords and the evidence that backs them. Use
when mapping screening questions to examples. Update when backing changes.

Rules of use:
- WORK-backed examples can anchor any answer.
- PERSONAL-backed examples only where the poster allows (see STAR-GUIDE §5).
- VERB RULE column: the strongest verb you can honestly use. Don't upgrade.
- Before raising any verb ceiling based on recall, calibrate with the
  ladder: watched / ran-with-IT / ran-solo / owned. A loose first
  phrasing ("did a good amount of server stuff") can overstate; the
  ladder settles it.
- Magnitudes marked NEED are facts only the applicant knows: the agent
  must ask for them before drafting answers that cite them, never guess.

How to fill: one row per skill/claim you might make in an answer. Be
brutal in the Verb ceiling and Under-probe columns; they are what stop a
bad answer before it is drafted. Delete the example rows once real rows
exist.
